# NexoIT

Modern dark-themed website for NEXOIT, built with Next.js.

## Pages

- Home
- Services
- Service detail pages
- Packages
- About
- Industries
- Contact

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3010](http://localhost:3010) when running with:

```bash
npm run dev -- --port 3010
```

## Build

```bash
npm run build
```
